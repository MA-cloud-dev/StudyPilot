学习：Pandas Series 基础

进度：1/4

1. 什么是 Pandas Series ？

Pandas Series 是一维带有标签的数组对象，它可以包含任何数据类型（整数、字符串、浮点数、Python对象等）。轴标签统称为索引（index）。可以把 Series 看作是 Excel 表格中的一列。

import pandas as pd import numpy as np s = pd.Series([1, 3, 5, np.nan, 6, 8]) print(s)

核心属性

  • values : 获取数组的数值部分
  • index : 获取数组的索引对象
